# Sources and interpretation

Verified documentation access: 2026-10-27. This package contains original audit procedures, reporting conventions, fixtures, and examples, not copied articles or third-party designs.

- [W3C Easy Checks](https://www.w3.org/WAI/test-evaluate/preliminary/): initial accessibility evaluation and the limits of preliminary checks.
- [WCAG 2.2 Quick Reference](https://www.w3.org/WAI/WCAG22/quickref/): standards navigation. The audit-dimensions reference links individual Understanding pages for selected criteria. These checks are not a complete conformance assessment.
- [Jakob Nielsen, Severity Ratings for Usability Problems](https://www.nngroup.com/articles/how-to-rate-the-severity-of-usability-problems/): impact, frequency, and persistence as considerations. The package's named severity, priority, and confidence levels are its own reporting rubric, not a reproduction of Nielsen's numerical scale.
- [Agent Skills specification](https://agentskills.io/specification): Markdown skill directory, frontmatter, and progressive loading.
- [Skills CLI](https://github.com/vercel-labs/skills): optional repository-based installation and skill selection.
- [Figma developer documentation](https://developers.figma.com/docs/figma-mcp-server/): optional Figma tool integration. Actual capabilities and authorization depend on the host environment. This package does not include a Figma connector or claim authenticated file access was tested.

The companion Laws of UX skill may help explain a mechanism, but it is optional and no sibling files are required. Accessibility standards, UX heuristics, design recommendations, and observed behavior are different evidence types. Numeric or user-outcome claims require their own support. Source links may require internet; the bundled procedures and supplied-artifact audit workflow work offline.
